# Как вносить изменения

1. Для свежей ссылки сначала создать запись в `inbox/` или заметку по `templates/source-note.md`.
2. Проверить первоисточник, claim, дату, ограничения и связь с конкретным решением.
3. При изменении инженерной позиции обновить `ADOPTION.md` и добавить запись в `CHANGELOG.md`.
4. Запустить `make check`.
5. В PR кратко описать evidence, impact и rollback/stop condition для эксперимента.

Язык заметок — русский; оригинальные названия методов, метрик и API оставляются на английском, чтобы их можно было искать.
