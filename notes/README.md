# Source notes

Здесь хранятся рабочие карточки источников, выбранных как `note` при triage.

`make triage` создаёт только заготовку: claim, evidence, ограничения и вывод необходимо заполнить после чтения первоисточника. После проверки источник можно оставить в статусе `watch`, перенести в `SOURCES.md` и тематический раздел либо отправить на adoption review.
