# Source notes

Здесь хранятся рабочие карточки источников, выбранных как `note` при triage.

Для arXiv исход `note` теперь создаёт versioned deep summary в `papers/`, а не
пустую карточку по дате. Здесь остаются legacy notes и карточки источников без
полнотекстового paper pipeline. После проверки источник можно оставить в
статусе `watch`, перенести в `SOURCES.md` и тематический раздел либо отправить
на adoption review.
