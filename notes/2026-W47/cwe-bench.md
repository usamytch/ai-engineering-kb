## Original-language synopsis

The public release contains repository-level security repair tasks with executable verifiers. Task curation checks that requirements are inferable, reference fixes pass, and existing functionality remains intact.

## Мой вывод

Ценность здесь — проверяемый результат исправления и требования к качеству самих задач. Это полезнее очередного сравнения ответов на вопросы об уязвимостях.

Сто задач покрывают 91 класс CWE, но такая широта не даёт глубокой оценки каждого класса. Детерминированный verifier также не делает стохастические прогоны агента воспроизводимыми автоматически. Нужны закреплённые версии среды, повторные попытки и явное различение среднего результата попытки и pass@k.

Публичный набор может загрязняться обучением; закрытый контрольный набор требует отдельного доступа. Долю пройденных задач нельзя переносить на вероятность безопасности произвольного репозитория. Для нашего чтения это пример полезного дизайна evaluation, а не основание выбирать победителя по небольшой разнице leaderboard.
