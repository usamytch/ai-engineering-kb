# Discovery snapshot — 2026-08-01

Это вручную проверенный seed, а не автоматическая подборка.

## Протоколы и runtimes

- **MCP specification 2026-07-28** — latest spec на дату проверки. В overview появились optional extensions для asynchronous Tasks, Skills over MCP и MCP Apps. Статус: `trial`, обязательно фиксировать version и security boundary. [Specification](https://modelcontextprotocol.io/specification/2026-07-28)
- **A2A 1.0** — open agent-to-agent protocol под governance Linux Foundation. Не путать с MCP и internal subagent calls. Статус: `explore`. [A2A](https://a2a-protocol.org/latest/)
- **Google ADK 2.0** — agent framework с graph workflows, multi-agent, runtime, evaluation и observability. Статус: `watch/framework comparison`. [ADK](https://adk.dev/)
- **OpenAI Agents SDK** — lightweight agent loop, tools, handoffs, guardrails, sessions, human-in-the-loop и tracing. Статус: `watch/framework comparison`. [Docs](https://openai.github.io/openai-agents-python/)
- **GraphRAG v3.1.0** — latest release, показанный официальным репозиторием при проверке, датирован 2026-05-28. Статус подхода: `explore`, не general-purpose upgrade. [Repository](https://github.com/microsoft/graphrag)

## Agents и evaluation

- **Demystifying evals for AI agents** (Anthropic, 2026-01-09) — практический guide по нескольким grader types и evaluation сложных trajectories/outcomes. Статус: `promote to core source`. [Article](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)
- **Trustworthy agents in practice** (Anthropic, 2026-04-09) — useful architecture lens: model, harness, tools, environment; human control и layered security. Статус: `promote to safety`. [Article](https://www.anthropic.com/research/trustworthy-agents)
- **How Many Tasks Are Enough for Agent Benchmark Decisions?** (2026-07-14) — показывает, что безопасная доля partial run сильно различается между benchmarks. Статус: `watch`; полезный аргумент против произвольного сокращения eval. [Paper](https://arxiv.org/abs/2607.12338)

## Agentic RAG

- **A-RAG** (2026-02) — keyword search, semantic search и chunk read как hierarchical interfaces, которыми управляет модель. Статус: `explore/trial pattern`; сравнить с one-shot hybrid+reranker. [Paper](https://arxiv.org/abs/2602.03442)
- **SoK: Agentic RAG** (2026-03) — taxonomy и framing как sequential decision process; полезен для карты risks/evaluation, claims требуют проверки по оригинальным работам. Статус: `watch/survey`. [Paper](https://arxiv.org/abs/2603.07379)
- **Agentic-R** (ACL 2026) — retriever оптимизируется с учётом local passage relevance и global answer utility в multi-step search. Статус: `watch/research`; production adoption преждевременен. [Paper](https://aclanthology.org/2026.findings-acl.785/)

## Итог snapshot

Главный тренд — сближение RAG и agents: retrieval превращается из одношагового preprocessing в управляемый моделью набор инструментов. Инженерный ответ на этот тренд — не «всё сделать agentic», а добавить explicit retrieval interfaces, budgets, final-state eval, context provenance и security boundaries.
