## Исходные источники

Запрос arXiv остался прежним: `agent` либо `retrieval augmented generation`.
Пройдена 31 страница по дате последнего обновления, до записей старше начала
периода. Пройдены также все 16 страниц восьми источников GitHub releases:
OpenAI Agents SDK, LangGraph, Google ADK, MCP, A2A, GraphRAG, Ragas и vLLM.
Ограничения на количество записей не было.

Границы в [manifest.json](manifest.json):
`2026-10-16T13:47:13.261442+00:00` — `2026-11-20T07:55:32.718104+00:00`.
Начало взято из последнего полного октябрьского снимка. История предыдущих
inbox и версий papers участвует в дедупликации; новая версия не удаляется
только потому, что работа уже известна.

Это покрытие настроенного запроса, не всей AI-литературы. Широкое слово
`agent` приносит также экономику, химию и классическое управление. Эти записи
остаются доступными с объяснением первичного отбора. Напротив, работы по
обучению и inference без этих терминов могут не попасть в arXiv-выборку.
Живой API не предоставляет транзакционный снимок и все промежуточные версии.

Четыре RSS полностью прочитаны как снимки лент. Все записи имеют даты,
старейшая запись каждой ленты предшествует началу периода. Это позволяет
проверить достигнутую границу, но не доказывает, что издатель никогда не удалял
записи или включает в RSS весь архив. Для этих источников учитывается дата
публикации; история правок не восстанавливается. Поле `complete` относится
к указанному в `scope` способу обхода, а не к гарантии полноты архива.

У Anthropic дата каждой выбранной статьи дополнительно сверена с
`Article.datePublished` на самой странице. Видимая часть индекса уже достигает
старых публикаций. Если при будущем длительном перерыве этого будет мало,
адаптер остановится с явным сообщением о необходимости пагинации. Sitemap
не используется для датирования: массовое изменение `lastmod` после смены URL
не означает публикацию новой статьи. Другие исследовательские команды Anthropic
этим индексом не охвачены.

## Как оценивалось содержимое

Каждой записи соответствует отдельный анализ аннотации, RSS-описания или
release notes: предмет, тематический приоритет, краткая оценка и точная
цитата-основание. Отсутствующее описание явно отличается от прочитанного
abstract. Хеш входа позволяет заметить устаревший анализ после изменения данных.

Первичный приоритет `read` означает кандидата на дальнейшее чтение. Он не
равен включению в редакционный список важных работ. Для этого отдельно
рассмотрены метод, сравнимость baseline, ограничения, стоимость и применимость.
Подробные разборы перечислены в [reading-selection.json](reading-selection.json)
и [web-reading.json](web-reading.json), выводы — в [маршруте чтения](reading-guide.md).

Публикация в блоге производителя не делает утверждение независимо проверенным.
Рекламные анонсы, клиентские истории и нетехнические эссе сохраняются в общем
каталоге, но не превращаются в научные результаты. Например, The Silent Consensus
оказался эссе об институтах и человеческом контроле, а не исследованием
согласованности ответов моделей.

Девять выбранных веб-публикаций сохранены локально с хешами HTML и извлечённого
текста. Три страницы OpenAI прочитаны через веб-ридер после HTTP 403 при прямой
загрузке; для них нет локального хеша первоисточника. Это отражено в реестре.
Эксперименты из публикаций не воспроизводились; разборы имеют статус `ai-draft`.

## Что улучшено в сборщике

- RSS теперь разбирается как XML: CDATA больше не портит заголовки и не теряет описания.
- Сжатые gzip-ответы распаковываются перед сохранением кеша.
- Полнота RSS имеет явную область действия; неизвестная полнота обычной ленты по-прежнему считается незавершённым обходом.
- Анализ аннотаций сохраняется по частям; при ошибке цитаты повторяется только проблемная запись.
- Локальный каталог проверяет полное соответствие анализа текущему manifest перед сборкой.

Новые снимки следует сохранять в новой папке кеша. Повторное использование
кеша предназначено для возобновления одного сбора, а не для проверки свежести
на следующий день.
