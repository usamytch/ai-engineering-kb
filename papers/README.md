# Papers

Здесь хранится проверяемый, versioned результат разбора статей. Для arXiv путь
имеет вид `papers/arxiv/<paper-id>/versions/vN/`.

В Git попадают metadata, hashes, structured analysis и Markdown summary. Сами
HTML, PDF, TeX и нормализованный полный текст лежат локально в `.aidb/` и
намеренно не коммитятся.

`v2` всегда создаёт новую ревизию и никогда не перезаписывает анализ `v1`.

`analysis.json` явно фиксирует язык результата. Весь аналитический текст
сохраняется на доминирующем языке оригинала, а evidence quotes остаются дословными.
