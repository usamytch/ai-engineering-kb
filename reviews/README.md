# Adoption reviews

Здесь хранятся проверки подходов, выбранных как `review` при triage.

`make week-process` для `[r]` сначала делает full-text deep summary, затем
создаёт scaffold с hypothesis, baseline, experiment, budgets и stop condition.
Статус в `ADOPTION.md` меняется только после заполнения review и получения
достаточных локальных результатов.
